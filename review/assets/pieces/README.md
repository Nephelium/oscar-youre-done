# 棋子与棋盘素材

2026-10-20 使用内置 imagegen 生成，未使用 CLI API。五套棋子经用户选择后收录，`duo` 为默认。多邻国风格参考用户提供及测试中的多邻国棋盘外观，其角色和产品标识属于各自权利人，本应用与多邻国无隶属关系。其余木雕、陶瓷、像素、彩纸为生成的新设计。

- `sheet-*.png`：原始透明图集，每行依次王、后、车、象、马、兵，上白下黑。
- `<风格>-<颜色><类型>.png` / `<风格>-night-<颜色><类型>.png`：120 个日夜版 384 × 384 透明棋子。机械裁切与缩放保留生成的透明通道、相对大小和底部对齐。
- `board-sheet-*.png`：生成的木纹、石材、纸艺材质，左浅右深。
- `board-*-light.png` / `board-*-dark.png`：棋格纹理，布局由页面精确构成 8 × 8 网格。
- `prompts.json` / `night-prompts.json`：完整最终提示词集。
- 五套均有独立夜间图集，夜间提亮黑棋边缘；多邻国按用户最新官方日夜截图修正。原始截图不公开分发。
- 多邻国默认 100%，其他四套默认 112%，每套可独立调整 85%～125%。
- `extraction.json`：各棋子提取位置、缩放参数。

从这些图集重新生成：`node tests/prepare-review-raster.cjs`，需要 Sharp。脚本只裁切、等比缩放与透明画布合成，不绘制棋子。旧 SVG 保留供历史追溯，当前外观选择使用 PNG。
