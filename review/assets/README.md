# 图标

`oscar-panic.png` 为井井于 2026-10-20 选定的奥斯卡抱头惊恐、黑王倒下图标。使用内置 Imagegen，依据井井提供的多邻国课程角色截图生成。角色原型来自 Duolingo，图标随公开测试版分发，角色权利归原权利人。

最终提示词：单个正方形 Android 图标，保留奥斯卡黑色蓬发、粗眉、胡须、粉色上衣，双手抱头、瞪眼张口，前景为倒下的黑王。浅鼠尾草绿满版背景，奶油色棋格、少量金色惊恐线条，圆润柔和质感，移除文字、选项字母、外框与比较图。

此素材由网页顶部与 Android 图标共用。备选对比图保留在 recorder 的 build/reports/，不打包进入 APK。

## 棋子与棋盘

`pieces/duo-*.svg` 为原创圆润棋子，参考多邻国灰白棋盘的简洁配色与圆润轮廓。`pieces/mono-*.svg` 为原创几何棋子，两套均由 `tests/prepare-review-pieces.py` 生成，不含外部位图或字体。经典棋子沿用 `vendor/pieces/`。棋盘配色定义在 `review/themes.js`，界面外观设置与截图识别的校准样式相互独立。原创棋子随软件以 GPL-3.0 提供。
