# 奥斯卡你完了 1.1.1 · 复盘体验更新

这次重点调整手机上的曲线、评价视角和演示体验。

- 修正坐标轴文字纵向拉伸，曲线仍保留充足高度，支持 ±2 / ±5 / ±10 兵范围与点选回看。
- 翻转棋盘后，评价分数、候选分数、曲线、评价条和表现统计一起切换到棋盘底部一方。
- 演示换为 18 回合、35 步的完整对局，附带 Stockfish 19 深度 20、三候选的整盘分析，打开即可复盘。
- 棋子右上角与棋谱同步显示理论书本、首选星标及 ! / ✓ / ?! / ? / ??。标记随当前回看步更新，推演时不沿用主线评级。
- 新演示及其分析、变化不写入手记。旧版保存的演示移到首页独立入口，原有变化保留，可主动转为正式手记。
- 修复终局仍提示对手应手、将杀损失显示为巨大兵值，以及中途练习、黑方先走时的回合编号。

安装 `oscar-youre-done-1.1.1.apk` 可覆盖升级 1.1.0，保留棋谱与 Elo 数据。最低 Android 8.0，支持 ARM64 / x86_64，沿用 debug 测试证书。

预置分析的引擎来源、深度与开局理论出处见仓库 `review/demo-analysis.md`。ARM64 本地引擎为 Stockfish 19，x86_64 为 Stockfish 16.1。手动重新分析会使用当前设备引擎与所选用时。

附件包含 APK、SHA-256 校验值及引擎对应源码材料。真实画面回归样本沿用 [1.1.0 Release 的 duolingo-vision-fixtures.zip](https://github.com/Nephelium/oscar-youre-done/releases/tag/v1.1.0)。

实际验证：独立 App 的 15 项核心测试、4 组浏览器交互回归、两个 Android 模块的单元测试 / lint / 构建及 4 项 Android 画面回归通过。六种宽度下坐标文字保持等比例。最终 APK 已在模拟器升级安装，预置 36 个局面、棋子角标、本地引擎推演与重分析通过，40 篇既有手记逐条比对保持不变。安装后的 APK 与交付文件 SHA-256 一致。

这是 Android 模拟器验证结果，本次未连接物理手机。
