# 1.3.3 识别回退与精确起点

- 使用用户授权提供的 275 秒 H.265、720×1280、带黑边录屏复现。原视频及截图仅保留本地，不进入公开仓库、主 APK。
- 对照顺序解码和系统取帧，分别记录解码、识别耗时、确认走法及失败时间。用失败局面验证根因，优先恢复准确性，禁止以放宽阈值制造通过。
- 同时复核实时采集共用路径。型号仅为诊断信息，不按品牌硬编码。
- 切换应用时空白首帧不能耗尽初始校准机会。等待期间有界重试，校准成功或开始走子后停止。
- 结束画面在旧棋盘范围内被分类成全空时，按棋盘暂时消失处理。无双方王的画面不能新增棋谱缺口，真实已有缺口保留。
- 对照评估稀疏采样、唯一合法短路径补齐及中间帧细查。录屏仅支持不能悔棋的对局，练习题使用截图；仍需核对合法往返走法，不能把重复局面误作静止画面。分别计量解码转换与识别，未经完整录屏验证的提速不进入交付。
- 分支自动保存至少需要 3 个新半回合；与已保存路线分岔时从分岔点重新计数。手动保存不限步数，已保存路线的无分岔延伸持续更新同一分支。短试走只保留在当前工作区，既有手记不清理。
- 起点新增分钟、秒数输入，与滑块及预览同步，校验空值、非法值和末尾边界，保留选框。
- 修复仅截图手记的对比分支拖动：无实战步数时使用已选分支，返回起点后仍可拖回该分支，覆盖真实滑块拖动与键盘操作。
- 修复后检查现有实际画面、选中棋子、撤回、升变、日夜与缺口续录。运行界面、核心及两个 Android 模块要求的检查，覆盖安装本地 APK。实际手机耗时与模拟器耗时明确区分。
