# 1.3.6 终局校对修复

井井已授权修复补录、兼容旧对局，测试后交付 APK 并更新 GitHub 源码与 Release。

- 在共享 core 中集中实现补录提交与单条人工确认。明确保存所处理的疑点，记录修订历史，保留其他缺口。编辑主线后重新计算终局胜负，非终局恢复未结束状态。
- 读取旧对局时从合法棋谱恢复终局结果，仅自动关闭明确属于结尾未确认、且已能确认终局的提示。保留疑点记录和解决原因，不修改 schema，不批量覆盖磁盘文件。未知疑点或关联续录缺口继续等待核对。
- 提供不补走即可确认该处棋谱完整的入口，二次确认后只处理选中的一项。校对中的选中项随页面恢复保存。
- 完整对局一旦记录到合法终局，后续结算/动画画面不再制造疑点。练习题保留回退能力。结束提示增加类型字段，重复结束不重复追加。
- 核心、界面与实际 APK 验证将杀、和棋、旧记录、多个疑点、取消、重载、导出及原生终局采集。执行既有测试、两模块原生测试/lint/构建。发布 1.3.6 并核对附件哈希。
