# v1.3.2 实时连续记谱修复

井井反馈：日间模式能记录前三至五步，继续走子后持续需要校对。当前未取得这段手机录屏，先用已有真实多邻国画面与可控漏帧序列复现代码中的恢复瓶颈。

## 范围

- 测量棋盘识别、合法走法匹配和完整采集周期的耗时。
- 消除候选局面重复将死判断，以及同一失败画面的重复全量搜索。
- 根据目标棋子位置剪枝，补回唯一可确定的三至四步。存在不同合法顺序或搜索达到预算时保留校对提示，不猜棋谱。
- 优化采样节奏与稳定确认，持续不匹配时重新检查棋盘范围，恢复后消除已解决提示。
- 保留双方朝向、日夜模板、练习撤回、易位、吃过路兵、升变和将死动画的识别行为。
- 追加井井确认的录屏提速：仅比较棋盘，连续静止画面复用识别结果。差值相对于上次实际分类画面计算，避免逐帧微小移动累积后漏检。保留视频时间轴采样和稳定确认，直接请求缩小后的解码画面，减少高分辨率像素复制。
- 追加井井要求的缺口续录：短缺口唯一确定时自动补回。无法确定完整路径时，用稳定的完整局面作为下一段候选起点，再由后续合法走子确定行棋方。原棋谱保留，后段另存为关联续录，在复盘中提供前后段跳转，双方连接处仍待校对。使用现有 capture 扩展字段，无存储迁移或旧记录覆盖。截图无法证明的易位权标记为推定。
- 选中与取消选中、可走格提示仅触发重识别，不能作为走子依据，补充真实选中画面及受控提示覆盖测试。
- 录屏采用 MediaExtractor/MediaCodec 顺序解码，每 200 毫秒取样，避免每次从关键帧重新解码。仅对取样画面转换像素，无法提供兼容 YUV 画面的解码器从当前时间退回原取帧路径，保留此前确认的走法。
- 追加分支对比：局面起伏可勾选最多六条保存分支，以不同颜色绘制同一时间轴，支持兵值、胜率和翻转视角。点击分支点打开对应局面。相同起点、相同走法前缀的短分支合并至长分支，共享 FEN 分析保留；有实际分歧的分支各自保存。既有记录读取时使用同一去重规则，无 schema 变更。

## 验证与交付

运行 JVM 规则回归、真实画面 instrumentation 测试、可控漏帧及采集服务端到端回归，记录同设备修复前后耗时。运行项目要求的 npm test、两个 Android 模块 testDebugUnitTest/lintDebug/assembleDebug。交付本地更新 APK，记录已验证范围及手机实战仍待井井确认的部分。私人画面仅保留在本地测试目录。
