# 奥斯卡你完了 1.3.2 · 连续记谱与断点续录

- **连续识别提速。** 减少重复棋子匹配，采集周期包含识别耗时，持续匹配失败时重新定位棋盘。
- **静止画面快速跳过。** 只检查棋盘变化，静止局面复用识别结果。点选棋子、高亮和可走格圆点不会直接计作走子。
- **短缺口自动补齐。** 最多搜索四个半回合，合法顺序唯一时补回。存在多种顺序或搜索超出预算时保留校对位置。
- **大缺口继续记录。** 从后续清楚的局面和合法走子确定新起点，保存为关联续录。前段、后段可以在复盘中互相跳转，缺失的历史仍留待校对。
- **录屏顺序解码。** 避免对每个采样时间重复跳转解码，支持练习题撤回。已有设备解码器不兼容时自动使用原取帧方式继续。
- **同时比较分支。** 局面起伏可勾选最多六条保存分支，用不同颜色叠加。兵值、胜率与双方视角同步切换，点击曲线上的点即可回看，也可集中分析所选分支。
- **合并重复的短分支。** 同一起点下，完全包含在长分支开头的短分支自动合并，已有局面分析保留。真正走出不同路线的分支继续分别保存。

安装 `oscar-youre-done-1.3.2.apk` 可覆盖升级并保留手记。Android 8.0+，ARM64 / x86_64，沿用测试签名。Stockfish ARM64 为 19，x86_64 为 16.1。

检查与设备边界见 `docs/oscar-verification-1.3.2.md`。
