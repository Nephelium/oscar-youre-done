# 奥斯卡你完了 1.3.4 · 录屏与实时采集提速

- 录屏导入提前准备下一帧，与当前画面的识别交错进行，减少串行等待。
- 复用画面转换的数组和像素坐标，保留原有颜色计算、分辨率、采样间隔及识别阈值。
- 实时采集复用位图，合并裁剪与缩放步骤，减少高分辨率屏幕的分配和复制开销。
- 预读队列限制容量，停止导入时释放未使用画面和解码器；解码异常仍保留原有兼容读取方式。

安装 `oscar-youre-done-1.3.4.apk` 可覆盖升级并保留手记。Android 8.0+，ARM64 / x86_64，沿用测试签名。

同一段约 275 秒录屏，本轮旧版两次为 89.8 / 88.6 秒，新版三次为 68.8 / 74.1 / 70.0 秒，平均耗时减少约 20%。每次 67 步完全一致；原速全屏采集也记全 67 步，零未解决校对项。以上为模拟器结果。

实测耗时与验证边界见 `docs/oscar-verification-1.3.4.md`。
