# 奥斯卡你完了 1.2.0 验证与交付

## 实现

- 走子动画及设置开关，连续操作、前后回看、王车易位、吃子与升变。
- 三套棋子和四种棋盘独立搭配，默认原创圆润棋子与灰白棋盘。
- Stockfish WDL 千分比解析、白方统一存储、视角转换、旧分析补算与深度 20 演示更新。
- 曲线整体点击／拖动及下方连续滑块，读数同步显示回合和胜／和／负概率。
