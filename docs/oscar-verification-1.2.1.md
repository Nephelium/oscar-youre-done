# 1.2.1 验证记录

日期：2026-10-20。范围为独立 Android `:recorder`，原开局训练 `:app` 保留。

## 定位与修复

修改前的原生回归复现了两项问题：初始方向选择错误会污染棋子标签，已移动过两个半回合的棋盘也能被旧校准逻辑接受。新校准检查所有初始空格与占用格，并从棋子实际亮度核验朝向。

实时采集改为定时读取最新画面，生产方不再推送静止帧时仍可完成稳定确认。暂停、尺寸改变和本 App 前台期间隔离确认状态。预置数字特征支持首次练习和从开局前两步恢复，识别仍通过合法走法核查。

练习多步撤回保存独立变化。合法向前走子优先于回退，避免把正常重复局面判作撤回。

## 真实应用操作

环境：Android 16 API 36.1、1080 × 2400 的 x86_64 模拟器，多邻国 6.102.3，独立测试档案。

- 修订后的采集候选包在执黑、黑棋位于底部、整个屏幕共享的条件下，完成 70 步完整对局。黑方将杀，棋谱结果 `0-1`，无未解决校对项。
- 起录时白方已经走了 `e4`。中途进入本 App 再返回多邻国，棋谱连续。记录了静止画面复用的运行计数。
- 操作脚本有数次模拟点击未被多邻国执行。逐次检查画面确认棋子未动后，重新执行相同合法走法，记录继续；这些情况没有作为已完成走子跳过。
- 安装 1.2.1 后，对该盘全部 71 个局面执行本地 Stockfish 分析，验证保存变化、重新打开和 PGN 导出。
- 最终构建另从已经走过四步的实际局面起录，确认先走方后继续记录。短提示实际显示具体走法，随后消失；关闭开关、重新加载后不再显示，记谱继续。
- 实时记录控制页显示最近的外部棋盘画面，自动选框及四角控制点正常。

完整 70 步实战使用修订后的采集候选包。其后加入短提示并收尾界面文案，最终包进行了上述针对性检查。未连接井井的物理手机。
