# 奥斯卡你完了 1.3.0 · 边走边复盘，留住每一种想法

- **变化自动分析**默认开启。每走一步更新兵值、胜率、着法评级与棋子角标，快速走子先给结果，停留时继续加深。设置里可关闭、选择固定速度或自适应、调整深度上限。默认最高 20 层且限制计算时长，主动打开“不限深度”后才持续分析。走子、离开复盘或进入后台停止旧搜索。
- **分支自动保存**。不同步数的尝试分别保留，回看后改走会另存分支。分支逐步显示兵值与胜率，曲线以琥珀色和实战绿色区分；分支页显示各条末步分数。退回分出点会恢复实战界面，移除零步变化提示。
- **更具体的复盘说明**。显示实际吃子、升变、将军、合法攻击与引擎推荐线，数值变化浓缩为两枚数字。关键节点标出评价大幅变化与将杀，可自动播放到下一处转折。
- **手记左滑管理**。左滑或点“⋯”收藏、删除，删除前二次确认。支持自建收藏夹，完整备份保留收藏映射。
- **本地人机对战**。新增下棋页，Stockfish 六档棋力，可选执白 / 执黑，每步保存，支持恢复与局后复盘。复盘恢复全力搜索。
- **更紧凑的界面**。表现统计缩成顶部一行，缩减卡片留白，固定评价区高度。复盘增加小型控制格开关，白黑双方按格内面积比例显示控制。
- **看得见的录屏进度**。选择后立即显示读取状态，识别中显示进度、时间与已记录步数，支持收起、停止保留和完成后打开手记。

安装 `oscar-youre-done-1.3.0.apk` 可覆盖升级并保留手记。最低 Android 8.0，ARM64 / x86_64，沿用现有 debug 测试证书。Stockfish ARM64 为 19，x86_64 为 16.1。

本版的验证范围与结果见仓库 `docs/oscar-verification-1.3.0.md`。附件包含 APK、SHA-256 及引擎对应源码材料。
