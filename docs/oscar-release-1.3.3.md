# 奥斯卡你完了 1.3.3 · 识别修复与更清爽的分支

- 修复识别中途丢失棋盘范围的问题。点选棋子造成的短暂变化不会直接计作走子，初始校准遇到切换应用的空白画面后会继续重试。
- 棋盘消失、切到结束页时，不再把全空画面误报成一条漏记走法。
- 收紧棋子匹配结果复用条件，减少重复计算，同时保留原有分类阈值与合法走法核对。
- 录屏起点可直接输入分钟和秒数，支持小数秒，与时间轴和预览同步。录屏用于不能悔棋的对局，练习题请使用截图导入。
- 截图手记没有实战棋谱时，也能拖动保存分支的进度，退到分支起点后仍可继续前进。
- 新路线满 3 步后自动保存。手动保存不限步数，沿已保存路线继续走会更新同一分支；从中途岔出时重新计算 3 步。短试走保留在当前推演中，原有保存分支不清理。

安装 `oscar-youre-done-1.3.3.apk` 可覆盖升级并保留手记。Android 8.0+，ARM64 / x86_64，沿用测试签名。Stockfish ARM64 为 19，x86_64 为 16.1。

具体测试与计时见 `docs/oscar-verification-1.3.3.md`。
