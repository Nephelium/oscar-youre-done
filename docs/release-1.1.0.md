# 奥斯卡你完了 1.1.0 · Android 测试版

从多邻国对局自动记谱，结束后用本地 Stockfish 复盘，也能把一道练习题留下来慢慢推演。

本次更新：

- 应用改名“奥斯卡你完了”，使用奥斯卡抱头与倒下黑王的新图标，保留原包名、签名与棋谱。
- 支持从练习题当前局面起录，以及从系统图片选择器导入截图、确认局面并分析。
- 完整对局与小练习分为不同手记，支持修改分类、改名和确认删除。
- Elo 成长手记支持手动记分、补记时间、修改、删除、曲线与备份恢复。
- 局面曲线增高，加入 ±2 / ±5 / ±10 兵刻度切换和点选定位，棋子右上角同步显示走法评价符号。
- 修复多邻国低对比度全宽棋盘定位、将杀时王爆炸画面漏记最后一步，以及升变选择框遮挡后的恢复。

实际验证：Android 16 x86_64 模拟器中，新开的一盘多邻国真实对局记录完整 35 步，以 `Qh7#` 结束，无待校对项。36 个局面完成本地 Stockfish 分析，独立变化、重开与 PGN 正常。升后练习记录 9 步并包含 `d7d8q`。系统截图导入、分析、推演、删除范围和原图保留通过。

JavaScript 核心测试、手机界面检查、两个 Android 模块的单元测试 / lint / 构建及 4 项实际画面回归通过。lint 为 0 错误，保留第三方及平台 API 建议警告。

安装 `oscar-youre-done-1.1.0.apk`。最低 Android 8.0，ARM64 / x86_64。当前使用 debug 测试证书，物理手机适配尚待实机反馈。

附件包括 APK、校验值、真实画面测试样本，以及所分发 Stockfish 版本的对应源码材料。测试样本解压到 `android/recorder/build/reports/` 后可运行 Android 画面回归。
