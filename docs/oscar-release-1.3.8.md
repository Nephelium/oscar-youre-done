# 1.3.8 · 棋谱导出与复制

日期：2026-10-27。

- 单局导出新增代数记谱（SAN），例如 `1. e4 e5 2. Nf3 Nc6 *`，可保存为 `.txt`。
- PGN 和 SAN 都提供“导出文件”“复制”两种方式。PGN 保留对局信息和起始 FEN，可在其他棋类软件还原棋局。
- 移除单局导出弹窗的“完整备份”按钮。全局备份和旧 JSON 备份导入保留。
- 导出已保存的实战主线全谱，支持中途起录的真实回合数、黑方先走、易位、吃过路兵、升变和将军/将死记号。有待校对部分时提示导出范围。
- Android 与 iOS 共享界面、SAN 生成和原生剪贴板桥接同步更新。

## 下载与安装

本次只提供 Android 1.3.8（versionCode 15）APK，Android 8.0+，ARM64 / x86_64，沿用已有测试签名，可覆盖安装。

iOS 本轮仅更新源码，未编译、打包或进行设备验证。旧的 [1.3.7 未签名 IPA](https://github.com/Nephelium/oscar-youre-done/releases/tag/v1.3.7) 保留在原 Release，不包含本次导出改动。

## 验证

- JavaScript 核心测试及现有训练数据校验通过；新增 SAN 测试覆盖正常全谱、中局黑先、回合数、特殊走法、非法主线和 PGN 往返。
- 浏览器四个导出入口、文件内容、复制成功/失败与兼容路径、主线范围、窄屏/横屏/日夜布局通过。
- 两个 Android 模块的单元测试、Lint、构建通过。实际 1.3.8 APK 在 Android 模拟器覆盖安装、本地 Stockfish 分析与重载保存通过。
- 原生剪贴板测试从实际导出按钮写入系统剪贴板，PGN 与 SAN 内容一致。两种格式通过系统文件选择器保存，逐字核对实际文件；中途局面的 PGN 可还原 FEN 与全部走法。
- APK 内 199 个共享资源与引擎文件匹配当前源码，测试图片未进入主 APK。签名与 1.3.7 一致。
- iOS 本轮只执行 JavaScript 共享逻辑/桥接测试和 3 项 Python 打包脚本测试，未运行 Xcode 或设备测试。Android 物理手机本轮也未连接验证。

APK 继续附带校验文件与两个 Android 引擎的对应源码归档。
