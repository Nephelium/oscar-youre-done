# 奥斯卡你完了 1.2.1 · 记到每一步，看得见进度

- 修复实时记录可能停在 0～1 步的问题。棋盘静止时继续确认有效画面，切回本 App 时暂停识别自己的界面，回到多邻国后继续。
- 内置多邻国棋子特征，首次使用可直接识别练习题。标准开局会核对实际朝向，避免选错方向或开局已走两步时污染识别模板。
- 每次确认走子或撤回，会短暂显示具体走法和记录步数。**设置 → 走子识别提示** 默认开启，可以关闭。授予悬浮窗权限后使用连续短提示，未授予时使用系统文字提示。
- 实时记录页增加最新采集预览与返回多邻国入口。实时、截图、录屏均可自动定位棋盘，选框支持整体拖动、四角调整和重新绘制。
- 录屏支持选择起点、识别任意练习局面、确认先走方后记谱。练习中的多步撤回会保留为可推演的变化；正常重复局面按合法走子处理。
- 修复推荐箭头尖端与圆帽叠加的问题。选中棋子时隐藏推荐箭头，让可走位置更清楚。

安装 `oscar-youre-done-1.2.1.apk` 可覆盖升级，保留手记与 Elo 数据。最低 Android 8.0，支持 ARM64 / x86_64，沿用 debug 测试证书。

本轮在 Android 16 模拟器、实际多邻国 6.102.3 中完成执黑全屏采集：70 步，黑方将杀，零未解决校对项。整盘 71 个局面的本地 Stockfish 分析、分支、重开与 PGN 导出通过。最终包另验证中途局面起录、走子短提示、自动消失、关闭与设置持久化。

自动回归包括 8 项原生单元测试、10 项 Android 画面与视频测试，以及核心与界面检查。覆盖黑方朝向、晚起录两步、升变、练习撤回四步、带黑边录屏和可调整选框。物理手机未连接，本次模拟器验证不能代替每款手机的实测。

附件包含 APK、SHA-256 校验值及引擎对应源码材料。ARM64 使用 Stockfish 19，x86_64 使用 Stockfish 16.1。画面回归样本沿用 [1.1.0 Release 的 duolingo-vision-fixtures.zip](https://github.com/Nephelium/oscar-youre-done/releases/tag/v1.1.0)，新增视频由仓库测试脚本在本地生成。
