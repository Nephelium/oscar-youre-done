# 奥斯卡你完了 1.3.6 验证

日期：2026-10-22。环境：Windows、Edge 与 Android API 36.1 x86_64 模拟器。此次报告对应补录和终局修复，未重新测量录屏导入性能。

## 复现与修复

1. 旧版结束采集产生的结尾提示没有目标局面，补录提交仅按目标局面匹配来消除提示，因此补齐将杀后该提示仍未解决。
2. 旧版修改走法后没有重新计算胜负，实际将杀的棋谱仍可能保存为未结束。
3. 现在保存补录时明确处理所选疑点，合法终局重新计算胜负。其他缺口不随意清除；原主线、疑点和分支存入修订记录。
4. 旧数据读取时恢复合法终局的结果，只自动解决可明确识别的结尾未确认提示。其他疑点保留人工确认入口。未做 schema 迁移，也未批量覆盖旧文件。
5. 完整对局在已记录合法终局后忽略后续画面，练习模式仍保留回退。结束操作可重复调用，不重复追加提示。

## 实际执行

- 根项目 `npm test`：47 项测试及四组规则/数据验证通过，其中新增补录核心回归 6 项。覆盖黑方/白方将杀、和棋、多个疑点、无目标局面的旧提示、非法走法、分支归档、PGN 和备份。
- 新补录界面回归分别在直接文件模式与已安装 Android APK 通过：补上将杀、保存前重载、保存后重载、选中疑点清除、其他疑点保留、二次确认取消、无新走法确认、旧手记恢复、原生存储与 PGN 导出。
- 既有 12 个网页界面脚本通过：mobile、notebooks、growth、perspective、interaction、variation、session、navigation、theme、night、branch-comparison、capture-regression。
- 两个 Android 模块 `testDebugUnitTest lintDebug assembleDebug` 通过；recorder 单元测试 12 项，原训练模块 3 项。recorder instrumentation APK 编译通过。
- 实际模拟器 instrumentation 5 项通过：新增终局防误报与重复结束 2 项；真实多邻国完整对局、升变选择与升后、练习局面及回退 3 项。
- 真实多邻国完整对局画面确认将杀后，继续输入初始棋盘和空白画面，走法及疑点数量保持不变。未结束的采集仍保留结尾校对提示。
- 已安装 APK 的本地 Stockfish 整盘分析、逐局面保存、WebView 重载与分支引擎应手通过。
- APK 资产核查 199 项匹配共享源码、棋子、识别特征、规则库及引擎材料，测试图片未进入主 APK。
- 已安装的 base.apk 与交付包 SHA-256 一致。公开源码快照单独构建、单元测试与 lint 通过；除 META-INF 签名目录外，302 个 APK 条目与交付包逐项相同。私人回归录屏、完整棋谱及 instrumentation 辅助类未进入主 APK。
- 独立公开项目的 `npm test` 33 项、`npm run test:ui` 11 个界面脚本全部通过；它不包含原双棋种训练模块，因此与根项目测试数量不同。
