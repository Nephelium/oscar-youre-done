## 变化、分支与自动分析

`tests/review-variation.test.js` 与 `tests/review-variation-smoke.js` 覆盖：

- 实战棋谱不因推演而改变。回看变化后改走会保留旧路线并生成另一分支。
- 变化每步独立展示分数 / 胜率，切换白黑视角，主线与变化使用不同颜色。
- 退回分出点后移除变化提示，恢复实战游标。旧版保存的零步变化状态重开后也正确恢复，原推演保留在分支列表。
- 每步自动分析，关闭后不发送计算请求。默认渐进策略同时受时间与深度约束；不限深度只在显式开启后使用。
- 同引擎较浅结果不能覆盖较深缓存，旧任务取消后不能污染新的局面。不同引擎版本不直接比较走法损失。
- 两枚紧凑数字表达兵值与胜率变化，完整说明保留单位和上下文。将杀不会转换为虚假的巨大兵值变化。
- 说明正确提取吃子、升变、将军、将死及当前合法攻击，不把可能被吃描述为必然丢子。
- 关键节点选择与播放停止，控制格开关和棋盘翻转，原有动画及触摸曲线操作。

浏览器桥接桩只证明界面与请求状态。另运行 `tests/review-variation-android.js`，通过最终安装包的真实 Stockfish 链路验证：

- 人机对战完成四步，离开后重开继续同一记录，结束后进入复盘。
- `d4 d5` 分支起点与两个后续局面自动产生真实 WDL 和评价，每个深度均不超过设置的 12 层。
- 逐步退到分出点，零步提示消失；分支保存并可在重开后继续查看。
- 显式打开不限深度后，实时结果超过 12 层，持续更新；按 Android Home 进入后台后停止，观察期内缓存不再变化。
- 测试结束恢复默认自适应、最高 20 层和不限深度关闭。

## 原生引擎与采集回归

本轮完整 Android instrumentation 通过 11 项测试，包含既有 10 项视觉 / 记谱回归和新增 `StockfishPlayTest`。排查引擎关闭日志时发现读线程可能抛出未捕获的 IOException，修复后重新运行扩展后的引擎测试，通过，未再出现该退出崩溃。

引擎测试逐一调用六档 Skill Level 的白黑双方应手，验证合法性、升变局面、取消后恢复、分析时恢复 MultiPV 3 与 WDL、深度上限，以及无限搜索增量回调与取消。

视频导入另通过 Android 系统文件选择器实际导入包含多步撤回的受控练习录屏。结果为 6 步主线，撤回的 4 步保存在独立变化，0 个校对项。读取 / 处理弹窗显示进度和已记录步数，完成后由用户点开手记。

`tests/review-capture-regression-ui.js` 通过选框绘制、整体平移、四角缩放、时间定位、失败重试保留、练习确认和单轮廓箭头检查。

界面检查覆盖左滑与菜单入口、删除取消与二次确认、其他手记保留、自建收藏夹、备份导入时重复记录 ID 的收藏映射，以及执黑对战恢复与认输确认。

## 验证边界

本版没有连接物理手机。上述引擎和视频验证运行于 x86_64 模拟器，ARM64 已完成打包与原始二进制哈希核对，本轮未在 ARM64 真机运行。旧版真实多邻国完整实时对局及升变证据继续保留在对应版本验证记录中，不作为本版新增的真机测试。

本版修改录屏进度与复盘交互，没有改动视觉识别算法。不同手机采集权限、屏幕比例与多邻国版本仍需按实际设备反馈复测。
