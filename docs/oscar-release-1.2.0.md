# 奥斯卡你完了 1.2.0 · 走棋更连贯，棋盘随你选

- 加入平滑走子动画，支持前后回看、吃子、王车易位、升变与推演。设置中可关闭，系统减少动态效果时默认关闭。
- 三套棋子、四种棋盘可以自由搭配。默认使用多邻国风格的原创圆润棋子与灰白棋盘，另有经典雕刻、几何剪影、鼠尾草、奶油木纹和深海蓝。
- 局面起伏可切换兵值与胜率。胜率读取 Stockfish 的胜／和／负概率，翻转棋盘时同步切换视角；旧分析可以补算。
- 整块曲线和下方滑块均可左右拖动，连续回看局面，支持键盘操作。
- 固定复盘评价、推荐变化与对照按钮的布局，切换局面时下方不再随文字长短跳动。长说明可在卡片内滚动。
- 减少复盘重绘时的重复棋谱重放，移除切换设置时的整页淡入。演示重新预置 Stockfish 19 深度 20、三候选与整盘概率分析。

安装 `oscar-youre-done-1.2.0.apk` 可覆盖升级，保留棋谱与 Elo 数据。最低 Android 8.0，支持 ARM64 / x86_64，沿用 debug 测试证书。

胜率表示引擎自对弈模型估计的获胜概率，和棋单独显示，不根据个人 Elo 预测实战结果。ARM64 本地引擎为 Stockfish 19，x86_64 为 Stockfish 16.1。预置分析与概率来源见仓库 `review/demo-analysis.md`。

验证覆盖核心与 UI 回归、连续快点、易位及升变、36 个局面的评价区高度、外观选择与持久化、Android 上真实触摸事件的连续拖动、本地引擎整盘 WDL 和分支推演。既有 43 篇手记逐条比对不变。此次未连接物理手机。

附件包含 APK、SHA-256 校验值及引擎对应源码材料。画面回归样本沿用 [1.1.0 Release 的 duolingo-vision-fixtures.zip](https://github.com/Nephelium/oscar-youre-done/releases/tag/v1.1.0)。
