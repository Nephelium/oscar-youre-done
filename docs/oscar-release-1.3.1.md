# 奥斯卡你完了 1.3.1 · 看棋更连贯，棋盘更多样

- **关键节点就在前后步旁。** 导航依次为起点、上一关键节点、上一步、步数、下一步、下一关键节点、终点，取消独立关键节点栏目。跨步跳转统一在 1.2 秒内播放，步数越多越快，途中可再次导航或拖动中断。遵循走子动画开关。
- **整盘分析时自由浏览。** 前后步、曲线拖动与推演浏览不再取消整盘队列，计算在当前复盘页后台继续。
- **五套位图棋子、八款棋盘。** 多邻国棋子默认使用，另有木雕、青瓷、像素、彩纸。棋盘保留多邻国与鼠尾草，提供天然木纹、月光石、手作纸及深海蓝、薰衣草、玫瑰可可配色。
- **日夜与尺寸。** 五套棋子均配日夜素材，默认跟随系统，也可手动切换。夜间采用多邻国参考的蓝黑底与蓝灰边框。其他四套默认放大到 112%，每套可独立调整 85%～125%。
- **夜间也能识别。** 内置独立日夜模板，按画面选择；重新校准后保留另一套。官方日夜截图及夜间走子序列已纳入本地验证。
- **对战有了时钟。** 可选 3、5、10 分钟、15 分钟 + 每手 10 秒、不限时。默认 10 分钟，离开或后台暂停，返回后可继续。超时结束对局。设置可允许悔棋，默认关闭。
- **双方走子都有动画。** 修复 AI 思考状态刷新擦掉动画的问题。开启悔棋后会取消旧应手，防止迟到的结果重新落子。
- **横屏与按钮排版。** 棋盘与复盘区分列，右侧独立滚动；对战时钟放到棋盘旁。旋转时保留当前页面和计算。分析与推荐按钮分行，增加间距。

安装 `oscar-youre-done-1.3.1.apk` 可覆盖升级并保留手记。Android 8.0+，ARM64 / x86_64，沿用测试签名。Stockfish ARM64 为 19，x86_64 为 16.1。

具体检查与设备边界见 `docs/oscar-verification-1.3.1.md`。附件含 APK、SHA-256 和引擎对应源码材料。
